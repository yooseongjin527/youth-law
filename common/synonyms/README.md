# 분야별 동의어 사전 (평어 → 법률용어)

하이브리드 검색(BM25 + 임베딩)의 **쿼리 확장**에 쓰이는 분야별 동의어 사전입니다.
청년의 평어 질문에 법조문 용어를 덧붙여 검색 적중률(hit@k)을 높입니다.
각 담당자가 자기 분야 파일만 작성·관리합니다.

> 확장은 **검색 입력(임베딩·BM25)에만** 적용됩니다 — 답변 생성·인용·연락처에는 영향이 없어
> 환각 위험을 직접 늘리지 않습니다.

## 파일 구조

```
common/synonyms/
  labor.jsonl      ← 담당 A (노동)
  housing.jsonl    ← 담당 B (주거)
  consumer.jsonl   ← 담당 C (소비자)
  finance.jsonl    ← 담당 D (금융)
```

비어 있는 파일(housing/consumer)은 아직 미작성 상태입니다. 하이브리드 검색만으로도
현재 평가셋은 커버되며, 담당자가 아래 규칙대로 채우면 적중률이 더 올라갑니다.

## JSONL 형식

한 줄에 하나의 매핑을 작성합니다. 필드명은 `key` / `synonyms`.

```jsonl
{"key": "야근", "synonyms": ["연장근로", "가산임금", "야간근로"]}
{"key": "보증금을 안 돌려", "synonyms": ["보증금의 회수", "우선변제권"]}
```

## 매칭 방식 — substring (★ 토큰 매칭 아님)

쿼리에 `key`가 **부분문자열로 그대로 포함되면**(`key in query`) `synonyms`를 덧붙입니다.
형태소 토큰 매칭이 아니므로:

- 짧은 단어(`"야근"`, `"월급"`)도, **긴 평어 표현**(`"보증금을 안 돌려"`, `"퇴사를 안 시켜"`)도 트리거로 쓸 수 있습니다.
- 단, 활용형에 주의하세요. 예: `"짤리"`는 `"짤렸는데"`에 부분문자열로 없으므로 안 잡힙니다.
  활용 변화가 큰 표현은 사용자가 실제로 칠 법한 표면형(`"짤렸"`, `"잘렸"`)으로 쓰는 게 안전합니다.

## 작성 규칙

### key (평어 키워드)

- 사용자가 실제로 입력할 법한 **표면 표현 그대로** (활용형 포함 가능)
- 부분문자열로 매칭되므로 어근일 필요는 없음

### synonyms (법률 키워드 리스트)

- 인덱스에 적재된 **조문 텍스트에 실제로 등장하는 법률 용어**
- BM25·임베딩이 조문 본문과 매칭해야 하므로, 조문에 없는 단어를 넣으면 효과가 없거나 노이즈가 됩니다.

### 핵심 원리

```
key      = 사용자 입에서 나올 표현 (부분문자열)
synonyms = 조문 본문에 있는 용어
```

## 작성 순서

1. `evals/<분야>.jsonl`에서 자기가 작성한 평어 질문을 확인
2. 질문에 쓰인 평어 표현을 `key`로 추출 (사용자가 칠 표면형 그대로)
3. 그 질문이 매칭되어야 할 조문 본문에서 법률 용어를 `synonyms`로 추출
4. 한 줄씩 JSONL로 작성
5. `python common/rag_hybrid.py <분야>`로 hit@3/MRR이 오르는지 확인 (숫자가 안 오르면 개선이 아님)

> 참고: "뭔가요/무엇/뜻" 같은 **정의 의도** 확장(→"용어의 정의")은 분야 불문 공통이라
> `rag_hybrid.py`에 내장돼 있습니다. 여기엔 분야별 동의어만 작성하면 됩니다.

## 주의사항

- 파일 인코딩은 반드시 **UTF-8**
- 자기 분야 파일만 수정 (다른 분야 파일 수정 금지)
- JSON 문법 오류 주의: 쌍따옴표(`"`), 쉼표(`,`), 대괄호(`[]`) 확인
