# 분야별 동의어 사전 (평어 → 법률용어)

BM25 쿼리 확장에 사용되는 분야별 동의어 사전입니다.
각 담당자가 자기 분야 파일만 작성·관리합니다.

## 파일 구조

```
common/synonyms/
  labor.jsonl      ← 담당 A (노동)
  housing.jsonl    ← 담당 B (주거)
  consumer.jsonl   ← 담당 C (소비자)
  finance.jsonl    ← 담당 D (금융)
```

## JSONL 형식

한 줄에 하나의 매핑을 작성합니다.

```jsonl
{"key": "야근", "synonyms": ["연장근로", "가산임금", "야간근로"]}
{"key": "월급", "synonyms": ["임금", "임금 지급", "금품 청산"]}
```

## 작성 규칙

### Key (평어 키워드)

- 사용자가 실제로 쓸 만한 **일상 표현**
- 형태소 분석 후 매칭되므로 **어근 형태**로 작성
- 예: `"야근"`, `"월급"`, `"짤리"`, `"계약서"`, `"쉬라"`

### Value (법률 키워드 리스트)

- 인덱스에 적재된 **조문 텍스트에 실제로 등장하는 법률 용어**
- BM25가 조문 본문과 매칭해야 하므로, 조문에 없는 단어를 넣으면 효과 없음
- 예: `["연장근로", "가산임금"]`, `["임금", "임금 지급", "금품 청산"]`

### 핵심 원리

```
Key   = 사용자 입에서 나올 단어
Value = 조문 본문에 있는 단어
```

## 작성 순서

1. `evals/<분야>.jsonl`에서 자기가 작성한 평어 질문을 확인
2. 질문에 사용된 일상 표현을 Key로 추출 (어근 형태)
3. 해당 질문이 매칭되어야 할 조문의 본문에서 법률 용어를 Value로 추출
4. 한 줄씩 JSONL로 작성

### 예시 (노동 분야)

평가셋 질문: `"야근했는데 수당을 안 줘요"`

→ 근로기준법 제56조 조문 본문에 "연장근로", "가산임금", "야간근로" 등장

```jsonl
{"key": "야근", "synonyms": ["연장근로", "가산임금", "야간근로"]}
{"key": "수당", "synonyms": ["가산임금", "임금"]}
```

## 주의사항

- 파일 인코딩은 반드시 **UTF-8**로 저장
- 자기 분야 파일만 수정 (다른 분야 파일 수정 금지)
- JSON 문법 오류 주의: 쌍따옴표(`"`), 쉼표(`,`), 대괄호(`[]`) 확인
