## 1. 현재 verifier 동작 (D 적용 후)

위치: 전문가들(fan-in) → **verifier** → planner. 통과분만 `verified_answers`로 넘어가 사용자에 도달.

`_is_grounded(answer, citations)`:
1. **구조 가드** — 인용 없음 / snippet 비었으면 즉시 탈락
2. **Bedrock 판정**(verify 티어=Haiku) — 답변을 **통째로** 주고 "근거 조문 밖 법령사실(조문·숫자·기한·비율·권리)을 지어냈는가" YES/NO
3. **fail-open** — 판정 호출 실패 시 보수적으로 통과(파이프라인 단일장애점 방지)

캘리브레이션: **날조만 탈락**, 정직한 일반론·면책문구·동치환산(20분의1=5%)은 통과.
`verifier_agent`: `_is_grounded` 통과 **AND** `confidence ≥ 0.5` → verified.

## 2. 측정 현황 (housing 16문항 기준)

| 지표 | 값 |
|---|---|
| grounding rate | **1.0(가짜 stub) → 0.812(실측)** |
| 탈락 | 16 중 ~3건 |

- 탈락 성격: 대부분 **"검색 미스 → LLM이 검색 안 된 조문을 파라미터 지식으로 인용"** = CLAUDE.md 환각방지 원칙대로 의도된 차단 ✓
- 단, 탈락답 상당수가 **"나머진 멀쩡한데 한 부분만 드리프트"** → 통째로 날아감

### 2.1 B(문장 제거) 영향 규모 측정 (16문항)

| 항목 | 값 |
|---|---|
| 제거 문장 | 159 중 **11 (7%)** |
| 변형된 답변 | 8/16 (절반은 무변형) |
| floor 탈락(잔존<40%) | **0** |
| 변형된 답변 잔존율 | 75~92% (대부분 1~2문장만 제거) |

→ 현 D는 드리프트 답을 **100% 삭제**, B는 같은 답에서 **환각 1~2문장만** 빼고 75~92% 보존. 텍스트 변형은 외과적·소규모.

## 3. 문제점 / 보완할 점 (실제 사례 포함)

### P1 — 통째 이진 판정 → 과탈락 ★이번 타깃★
답변을 **통짜로** YES/NO만 봐서, 문장 하나라도 어긋나면 **답 전체 탈락**.

> **사례** — "이사 가야 하는데 보증금 못 받으면" 답변:
> *"…소액보증금 최우선변제(제8조)로 일정액은 먼저 받을 수 있고, 임차권등기명령으로 대항력도 유지되고…"* (+ 한 문장에서 제8조의 구체 금액 기준을 단정 — 조문엔 "대통령령으로 정함"만 있음)
> → 앞부분은 멀쩡한 근거 답인데 **마지막 한 문장 때문에 전체 탈락** → "정직 거절" → **사용자는 쓸 만한 70%마저 못 받음.**

### P2 — 경계 케이스 엄격
조문에 명시는 없지만 **합리적으로 도출되는** 내용을 "근거 없음"으로 깐깐하게 탈락.

> **사례** — "경매로 넘어가면" 답변: *"대항력이 있으면 임차권이 소멸하지 않고 낙찰자에게 대항할 수 있어요."*
> → 제3조의5(경매에 의한 임차권 소멸)의 **취지상 맞는 말**인데, snippet에 글자 그대로 없다는 이유로 탈락. **법적으로 맞는데 떨어짐.**

### P3 — 판정 비결정성
LLM 판정이라 **같은 답·같은 코드인데 실행마다 결과가 흔들림**(샘플링·시드 고정 안 됨).

> **사례** — 같은 16문항: 스코어카드 grounding **0.812**(≈3건) / 직후 per-item 프로브 **4건**(≈0.75).
> → 개선 전후 비교 숫자가 노이즈인지 진짜인지 헷갈림.

### P4 — 상류(검색) 의존
답이 드리프트하는 근본 원인은 **검색이 정답 조문을 못 끌어와** LLM이 기억으로 메우는 것. verifier는 **원인이 아니라 증상**을 막음.

> **사례** — "확정일자 도움?" 답변이 *"제3조의2 제2항에 따른 우선변제권…"* 인데, 그 질문 검색결과는 제3조의6/제8조/제7조 — **제3조의2가 안 끌려옴.** 검색 밖 조문을 인용 → 탈락.
> → 검색(E 하이브리드)을 고치면 애초에 드리프트가 안 생겨 통과될 답. verifier 단독은 **막기만 하고 품질은 못 올림** → 검색 개선과 짝.

### P5 — 발표 지표 미흡
차별점이 "환각 방지"인데 **"검증으로 환각 N건 차단(차단율 Y%)"** 집계가 없음(`verification_report`는 요청 단위).

> **사례** — 지금은 "16중 3 탈락"을 수동으로 셈. 데모에서 *"환각 의심 19% 구조적 차단"* 같은 자동 집계·시각화 도구 부재 → 가장 강한 세일즈 포인트를 숫자로 못 보여줌.

## 4. 개선 방안

### #1 문장 단위 검증 (이번 작업 — P1 해결, P2 완화)

- **① 문장 분리**: 한국어 종결어미/문장부호 + 줄바꿈 regex 휴리스틱(v1). 조문번호(제3조의2)·번호목록("1.")에서 안 끊기게 보호. (kss 등 라이브러리는 새 의존성이라 회피)
- **② 단일 LLM 콜**: 번호 매긴 문장들 + 근거 조문 → **근거 없는 문장 번호 배열** 반환. 비용은 현 D와 동일(1콜/답변).
- **③ 환각 문장 제거 + floor (B 채택)**:
  - 근거 없는 문장만 빼고 **나머지로 정제 답변** 구성 → 환각 문장은 사용자에 도달 안 함(차별점 유지) + 멀쩡한 부분은 보존(P1 해결).
  - **floor**: grounded 문장 비율 < 0.4(대부분 환각)면 통째 탈락 → 정직 거절. 토막난 답을 억지로 내보내지 않음.

> **A(비율 통과)를 안 쓰는 이유**: 비율로 "통과" 처리하면 소수 환각 문장이 **그대로 노출**된다. "환각이 구조적으로 도달 불가"라는 차별점을 깨므로, **제거(B)가 맞다.**

- **⚠️ 동작 변화**: verifier가 **답변 텍스트를 변형**(환각 문장 제거)한다 → 사용자에게 가는 답이 housing 원답과 달라짐. 공용 노드 동작 변경이라 PR에서 명시·합의 필요.
- **측정**: grounding rate + **과탈락 감소**(통째 탈락 → 부분 통과) + 환각 문장이 정말 빠지는지 전후 비교.

## 7. 측정 이력 — 단계별 before/after (housing 16문항)

| # | 단계 (verifier 상태) | hit@3 | MRR | grounding | 평균인용 | 비용($) | 핵심 변화 |
|---|---|---|---|---|---|---|---|
| ① | baseline (stub, 라벨 정정 전) | 0.75 | 0.583 | 1.0 ⚠️가짜 | 3.0 | 0.218 | 검증 없음(인용만 있으면 통과) |
| ② | 라벨 정정 (stub) | **0.875** | **0.667** | 1.0 ⚠️가짜 | 3.0 | 0.217 | 평가 정답 라벨 정정 → 측정 노이즈 제거 |
| ③ | D 통짜 LLM 판정 | 0.875 | 0.667 | **0.812** 실측 | 3.0 | 0.272 | 환각 차단 시작, 그러나 멀쩡한 답까지 통째 탈락(과탈락 3건, P1) |
| ④ | **B 문장 단위 (현재)** | 0.875 | 0.667 | **1.0** 실측 | 3.0 | 0.250 | 과탈락 0, 환각 문장만 제거(~7%/11문장) 후 통과 |

> ③(D, grounding 0.812)은 브랜치 정리 중 history에 커밋 안 돼 유실 — 세션 측정값 기재.

### 단계별 차이 요약
- **①→②** (평가셋): hit@3 +0.125, MRR +0.084. **검색 개선이 아니라** 정답 라벨 노이즈 제거 효과(측정 신뢰 확보).
- **②→③** (검증 도입): grounding 1.0(가짜)→**0.812(실측)**. 환각을 잡기 시작했으나, 한 문장 드리프트로 **답 전체를 버리는 과탈락**(P1).
- **③→④** (문장 단위): grounding 0.812→**1.0**, 과탈락 0. 환각 문장만 외과적으로 제거. 비용은 verify 콜로 소폭↑($0.21→0.25).

### ⚠️ 지표 해석 주의
**④의 1.0 ≠ ①②의 1.0.** ①②는 *무검증 통과*, ④는 *환각 문장을 실제 제거하고* 통과. grounding_rate(통과율)만으론 둘이 구분 안 됨 → **진짜 품질 지표는 검색 hit@3(0.875, 불변) + "제거한 환각 문장 수/율"**. 후자를 스코어카드에 넣는 게 P5(발표 지표) 후속 과제.
