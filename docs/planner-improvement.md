## 1. 현재 동작

fan-in 종합 노드: `전문가들 → [verifier] → planner → END`.
`verified_answers`(없으면 `domain_answers` 폴백)를 받아 최종 응답 생성. 3갈래:
1. 범위 밖 → 거절문
2. 통과 답변 0 → 정직 거절
3. 정상 → **분야별 블록을 기계적으로 이어붙임**(LLM 없음). `_build_block`(citations[:2]) + `_block_to_text` 나열.

출력: `final_answer`(텍스트), `answer_blocks`(카드 구조화), `messages`.

## 2. 실제 출력 — 복수 분야 "월급도 안 주고 보증금도 안 줘요" (노동+주택)

```
【주택 분야】               ← 질문은 "월급 먼저"인데 주택이 먼저
…월급(임금) 미지급은 근로기준법 영역이라 검색된 조문엔 없어요…   ← 주택 전문가가 노동 영역 침범
- 임금 미지급 → 고용노동부 1350      ← 본문에 연락처가 이미 들어감
- 보증금 미반환 → 대한법률구조공단 132
  ◆ 근거: 주택임대차보호법 제6조의3 …
     "계약갱신 요구 등. …① … ② … ③ … (9개 호 전체, ⑥항까지 raw로 박힘)"   ← 조문 전체 도배
  ☎ 대한법률구조공단 132 / 전세피해지원센터 1533-8119   ← 본문 연락처와 중복

【노동 분야】
stub: 노동법 관점 답변 …              ← labor 미구현(stub) 그대로 노출
```

## 3. 문제점 (실증)

- **P1 종합 부재(단순 concat)**: 맨 위 통합 요약 없이 분야 답을 통째 이어붙임 → 길고 산만, "그래서 핵심/뭘 먼저"가 안 보임.
- **P2 복수 분야 무순서·무연결**: 우선순위·행동 순서 안내 없음. 질문은 월급(노동)이 먼저인데 주택이 먼저 출력(fan-in 순서대로).
- **P3 근거 텍스트 길이 무제어**: `snippet`(조문 전체)을 그대로 박음 → 제6조의3 전체(①~⑥·9개 호)가 화면 도배, 가독성 파괴.
- **P4 분야 경계·중복 미정리**: 주택 전문가가 노동 안내까지 침범 + 연락처가 본문(LLM 생성)·구조화 contacts에 **중복**.
- (참고) labor stub 등 **품질 무관하게 그대로 노출** — planner가 거르지 않음.

## 4. 개선 방안

- **A. LLM 종합(요약+상세)**: planner가 Bedrock으로 맨 위 **통합 요약 2~3문장**(복수면 행동 순서 포함) 생성 → 그 아래 분야별 상세. **P1·P2 해결**. (비용+비결정성 부담)
- **B. 근거 snippet 절단**: 카드/텍스트에 핵심 N자(예 120)만 + 원문 링크 유지. **P3 해결**, 무LLM·간단·즉효.
- **C. 분야 순서 정렬**: 질문 등장 순/우선순위 기반(또는 A의 LLM 종합이 순서 결정). **P2**.
- **D. 연락처 중복 제거**: 전문가 프롬프트가 본문에 연락처를 안 쓰게(전문가 파일 영역 → planner 범위 밖, 별도 과제로 표시).
